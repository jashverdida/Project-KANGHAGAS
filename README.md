# ✦ Project KANGHAGAS

### A student hub for CTU San Remigio Extension

Project KANGHAGAS brings campus information and student services together in a welcoming, easy-to-use web experience. It is designed to help students connect with the SSG, keep up with campus updates, and find the support they need in one place.

> **One campus. One community. One helpful hub.**

## What’s inside

- **Student services:** Explore admissions guidance, request school documents, submit concerns, and send printing or uniform requests.
- **Campus information:** Browse announcements, check faculty availability, and view programs and student profiles.
- **SSG workspace:** A separate dashboard concept for reviewing requests, publishing announcements, and managing service information.
- **Community features:** Share feedback in Kwentuhan Corner and ask **Tambi the Owl**, the admissions helper.
- **A considered interface:** Responsive layouts, light and dark themes, and a warm campus-inspired visual style.

## Get started

The site is a self-contained static web page. Open `index.html` in a browser to explore it locally; there is no package installation or build step.

## Deploy with Vercel

This repository is prepared for Vercel’s static hosting:

1. Import `jashverdida/Project-KANGHAGAS` in Vercel.
2. Select **Other** as the framework preset.
3. Use the repository root as the project root. Leave the build command empty.
4. Deploy. Vercel serves the top-level `index.html` as the site homepage.

## Demo status & data

Project KANGHAGAS is a **front-end demo**, not a production student information system. Sign-in and admin features are client-side demonstrations; the page has no secure authentication service or connected database, and changes are not saved to a backend. Demo accounts are shown on the login screen.

Please do not enter real student records, personal information, or passwords. A production launch would require secure server-side authentication, access controls, and protected persistent storage.
